# Contributor guidelines

Everyday rules that turn the [engineering principles](../principles.md) and the
[architecture](../architecture.md) into code. Lint, formatting and the type check enforce what
they can; review checks the rest.

- [Runtime](runtime.md): Bun APIs over Node, imported from `bun`, and the allowed Node exceptions.
- [Code](code.md): naming, comments, imports, license headers, lint diagnostics and suppressions,
  formatting, dependencies and secrets.
- [Tests](tests.md): spec layout, factories, the test database and end-to-end tests.
- [Styling](styling.md): Tailwind, theme tokens, the design canvas and states.
- [Components](components.md): Astro or Svelte, UI primitives, composition and props.

Contribution workflow (branches, commits, pull requests and the check list) is in
[CONTRIBUTING.md](../../CONTRIBUTING.md).
