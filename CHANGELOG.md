# Changelog

All notable changes to stockpot are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

The foundation: a repository that builds, checks itself and documents how it is built. Nothing runs
as a product yet.

### Added

- A Bun workspace with the Astro server, Svelte and Tailwind in `packages/app`, and shared UI
  primitives and tokens in `packages/ui`
  ([#1](https://github.com/MrStnr21/stockpot/issues/1)).
- Linting with import boundaries between layers, formatting, type checks and Git hooks
  ([#2](https://github.com/MrStnr21/stockpot/issues/2)).
- A test harness for unit, database and end-to-end tests
  ([#3](https://github.com/MrStnr21/stockpot/issues/3)).
- CI workflows, Dependabot, issue forms and secret scanning
  ([#4](https://github.com/MrStnr21/stockpot/issues/4)).
- The AGPL-3.0-or-later license, SPDX headers in every source file and third-party notices
  ([#5](https://github.com/MrStnr21/stockpot/issues/5)).
- Engineering principles, architecture, contributor guidelines, the contributing guide, security
  and support policies, this changelog, the roadmap, and a check for broken links in the docs
  ([#6](https://github.com/MrStnr21/stockpot/issues/6)).
