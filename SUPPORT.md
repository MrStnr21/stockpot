# Support

stockpot uses GitHub issues for everything public; Discussions are turned off.

- **Bugs, feature ideas and documentation problems:** search the
  [open issues](https://github.com/MrStnr21/stockpot/issues) first, then open one with the matching
  [issue form](https://github.com/MrStnr21/stockpot/issues/new/choose): bug report, feature request
  or documentation.
- **Questions:** if the docs do not answer one, that is a documentation problem; ask it with the
  documentation form.
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md), never
  in a public issue.

What is planned, and in which order, is in the [roadmap](ROADMAP.md).
