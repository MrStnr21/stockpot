# Support

stockpot uses GitHub issues for everything public; Discussions are turned off.

- **Questions, bugs, feature ideas and documentation problems:** search the
  [open issues](https://github.com/MrStnr21/stockpot/issues) first, then open one with the
  [issue forms](https://github.com/MrStnr21/stockpot/issues/new/choose).
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md), never
  in a public issue.

What is planned, and in which order, is in the [roadmap](ROADMAP.md).
